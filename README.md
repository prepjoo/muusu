# 무우수 無憂樹

빗소리·범종·싱잉볼 듣기명상과, 녹음된 목소리로 안내하는 마음챙김 12가지를 담은 명상 웹앱입니다.
설치 없이 주소만 열면 쓸 수 있고, 휴대폰 홈 화면에 추가하면 앱처럼 열립니다. 한 번 열면 인터넷 없이도 동작합니다.

## 구성
- `index.html` 앱 전체 (화면, 소리 합성, 기록)
- `manifest.webmanifest` 홈 화면 설치 정보
- `sw.js` 오프라인 저장
- `icons/` 앱 아이콘
- `audio/` 마음챙김 안내 녹음 99개
- `vercel.json` Vercel 배포 설정

## 배포 (Vercel)
빌드 과정이 없는 정적 사이트입니다. Vercel에서 이 저장소를 가져오면(Import) 설정을 바꾸지 않고 바로 배포됩니다.
main 브랜치에 올릴 때마다 자동으로 다시 배포됩니다.

## 고칠 때
앱을 고쳐 올릴 때는 `sw.js` 맨 위의 `VERSION` 값을 하나 올려야 이미 설치한 사람에게도 새 버전이 들어갑니다.

## 기록
기록과 설정은 각 사람의 기기 안에만 저장되며 서버로 보내지 않습니다.
